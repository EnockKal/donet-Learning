# ASP.NET Learning & Exercises

This repository contains my **.NET practice projects, exercises, and notes** as I learn and improve my skills in **C# and .NET** (including ASP.NET Core).

I’m learning mainly from **codewithmosh.com** and building projects to strengthen my fundamentals, backend development skills, and real-world API building experience.

---

## What's Inside
 
- **Learning/** ? learning projects, experiments, and examples  
- **Projects/** ? larger projects (APIs, CRUD apps, etc.)

## Topics Covered

- **.NET & ASP.NET Core Fundamentals**
- **Building Web Apps with ASP.NET Core**
- **MVC (Model - View - Controller)**
- **Web API Development** (Controllers + Minimal APIs)
- **REST APIs** (CRUD, routing, request/response, status codes)
- **Entity Framework Core (EF Core)** (DbContext, migrations, relationships)
- **Database Integration** (SQL Server / PostgreSQL)
- **Authentication & Authorization** (JWT, roles, protected endpoints)
- **Validation & Error Handling** (model validation, global exception handling)
- **API Documentation** (Swagger / OpenAPI)
- **Configuration & Environments** (appsettings.json, secrets, connection strings)
- **Deployment Prep** *(later)* (publish, hosting basics)

- And more as I continue learning...
